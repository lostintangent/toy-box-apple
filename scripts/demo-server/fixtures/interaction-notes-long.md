# Interaction notes

The channel should make it easy to understand what happened,
what needs a response, and where the shared work lives.
A calm reading surface helps the team return to a conversation
without reconstructing the thread from memory.

## Reading the conversation

Messages should feel like one continuous exchange, even when the source
was wrapped to a fixed width before it was shared. The viewer can join
these source lines without closing the space between separate paragraphs.

A new paragraph starts a different thought. It needs a visible pause
rather than the tight spacing used between related list items.

## Keeping work in view

- Put a request where the reader can find it.
- Keep shared artifacts beside the conversation.
- Show who is working without interrupting the message.
- Let readers return to the newest message easily.

A decision often has context in an earlier message, so a link back to
the conversation helps the next person follow the reasoning.

## Returning later

The reader should be able to pick up where they left off. When a channel
has moved on, the current request and the newest message give them
a place to begin, while the history remains available for context.

Related work belongs together in the overview, but the conversation
should stay readable on its own. Each shared artifact has a name and
a place in the channel so another teammate can find it again.
